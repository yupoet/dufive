# Repository Guidelines

## Structure

`src/main.tsx` boots the React app. Keep pure Gomoku rules in `src/game/`, the
engine adapters in `src/engine/`, Zustand orchestration in `src/state/`, and
React views in `src/ui/`. Static GPL engine files stay isolated under
`public/engine/rapfi/`; never import them into the Vite application bundle.
Android is generated by Capacitor.

Two engines implement the same `EnginePort` contract (`src/engine/port.ts`):

- `src/engine/GomokuEngine.ts` — the built-in TypeScript search. It has its own
  Web Worker (`src/engine/worker.ts`) and degrades to a shallow main-thread
  search if the worker cannot start.
- `src/engine/rapfi/RapfiEngine.ts` — the GPL-3.0 Rapfi WebAssembly engine,
  imported lazily by `src/engine/createEngine.ts` so the 1.3 MB module stays
  out of the app bundle.

## Commands

- `npm install` installs locked dependencies.
- `npm run dev` starts Vite.
- `npm test` runs Vitest.
- `npm run lint` runs Oxlint (the vendored `public/engine/rapfi/rapfi.js` is
  ignored).
- `npm run build` type-checks and builds the PWA.
- `npm run icons` regenerates `public/icons/*.png`.
- `npm run build:android` creates `dist/dufive.apk`.
- `node e2e/smoke.mjs` runs the Playwright smoke test against a preview server
  on `http://localhost:4173/`. It exercises both engines, so it needs the real
  WASM build.

Use TypeScript/TSX with two-space indentation, single quotes, no semicolons,
and trailing commas. Tests live in the closest `__tests__/` directory and use
`*.test.ts`.

## Correctness and licensing

The TypeScript rules layer is authoritative: every human, hint, or engine move
must pass through `playMove` in `src/game/rules.ts`. Preserve serialized engine
calls and revision checks so stale worker replies cannot alter a restarted or
undone game.

Rule details worth remembering:

- `ruleSet` is fixed for a game. Renju restrictions (overline, double-four,
  double-three) apply to black only and must be gated on `ruleSet === 'renju'`
  — see `src/game/forbidden.ts`. Five in a row always beats a forbidden shape,
  in whichever direction it appears, so `forbiddenReason` scans every
  direction for an exact five before reporting an overline.
- Shapes are counted by their stone set, not per direction: `_XXXX_` is one
  four, while two genuinely different fours in one line (`XXX_X_XXX`) count as
  two. A three only counts when it becomes a *true* open four, i.e. both ends
  are empty and completing at either end makes exactly five — this excludes
  "false threes" whose completion would be an overline.
- Under renju rules a black overline is neither a win nor a legal threat, so
  the search takes an `exactFiveForBlack` flag and refuses to play six in a
  row for black.
- Forbidden points are filtered at the root of the search only; `findVcfWin`
  does not model them below the first move.

Rapfi is GPL-3.0. Keep its JavaScript/WASM, license, source provenance, and
rebuild instructions together under `public/engine/rapfi/`. Do not remove
`THIRD_PARTY_NOTICES.md` or redistribute the APK without corresponding source
availability.
